This repository holds two independent Next.js projects: `web/` (public site,
port 3000) and `admin/` (administration system and database owner, port
3001). Each has its own `package.json`, `node_modules`, `.env`, Prisma schema
and client, tests and scripts, and its own `CLAUDE.md`/`AGENTS.md` written by
`next dev`. Work inside the project you are changing; there is no root
`package.json` and nothing is shared between the two. See README.md.
